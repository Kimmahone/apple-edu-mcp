# Apple Edu MCP

**말로 요청하고, Numbers·Keynote·Pages에서 직접 고치는 수업 자료.**

Mac의 iWork를 AI와 연결해 학습지·발표 자료·수업 도화지를 만들고 수정합니다.

## 이렇게 요청하세요

> 5학년 시간과 용돈 관리 수업 자료를 Numbers로 만들어 줘. 그림과 그래프, 직접 고칠 수 있는 용돈 계산표를 넣고 예쁘게 구성해 줘.

> 제목을 바꾸고 용돈을 1만 원으로 수정해 줘. 원본을 남기고 새 파일로 저장해 줘.

## 설치하기

1. Mac에 Pages·Numbers·Keynote와 [Node.js 24 이상](https://nodejs.org/ko/download)을 준비합니다.
2. 설치 도우미 ZIP을 풀고 **설치하기.command**를 실행합니다.
3. 생성된 **AppleMCP/설정_안내.md**에 따라 AI 앱에 연결합니다.
4. “애플 MCP로 수업 자료를 만들어 줘”라고 요청합니다.

Claude Code·Codex·Antigravity에서 사용할 수 있습니다. 유료 Apple 개발자 가입은 필요하지 않으며, Apple 앱과 AI 서비스 이용 요금은 별개입니다.

## 업데이트하기

**업데이트하기.command**를 실행한 뒤 AI 앱의 MCP 연결을 다시 시작하세요. 이전 설치 버전으로 돌아가려면 **이전 버전으로.command**를 사용합니다.
