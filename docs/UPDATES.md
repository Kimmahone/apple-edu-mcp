# 업데이트와 되돌리기

**업데이트는 선생님이 실행할 때만 진행합니다.** MCP 시작 때 몰래 다운로드하거나 수업 중 앱을 종료하지 않습니다.

고정된 `launcher.mjs`가 현재 검증된 버전을 실행합니다. 새 버전은 별도 폴더에 설치하고 23개 도구의 연결을 확인한 뒤 `current.json`을 한 번에 교체합니다. 기존 연결은 재시작 전까지 이전 버전으로 동작합니다. 자료를 자동 변환하거나 삭제하지 않습니다.

| 도우미 | 동작 |
|---|---|
| 업데이트 확인.command | 공개 저장소의 최신 정식 버전과 현재 버전 비교 |
| 업데이트하기.command | 크기·SHA-256·압축 경로·패키지 버전 검사, 별도 설치·연결 시험 후 전환 |
| 이전 버전으로.command | 이전에 성공한 설치를 확인한 뒤 버전 전환 |
| 진단하기.command | 새 MCP 연결·23개 도구 확인; 문서·권한 변경 없음 |

네트워크·체크섬·설치·연결 실패 시 활성 버전을 바꾸지 않습니다. 같은 버전은 반복 설치하지 않고 두 업데이트의 동시 실행도 막습니다. 체크섬은 공개 릴리스와의 일치 검사이며 전자서명·Apple 공증을 대신하지 않습니다.

```sh
node "$HOME/AppleMCP/manage.mjs" check
node "$HOME/AppleMCP/manage.mjs" update
node "$HOME/AppleMCP/manage.mjs" rollback
node "$HOME/AppleMCP/manage.mjs" doctor
```

Node 실행 경로가 다른 경우 생성된 설정 안내의 경로를 사용하세요. 자동 강제 갱신은 하지 않습니다. 의존성 업데이트는 GitHub의 검토용 PR로 제안하며 자동 병합하지 않습니다.
